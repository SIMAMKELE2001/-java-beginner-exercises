Welcome! This repository contains 100 step-by-step Java exercises designed for absolute beginners.


Note: Each folder contains one exercise and an associated README.md.
More Instructions for use:

• You can clone this repository to your machine.
• You can navigate into any project folder (e.g.,*project-1*).
• Read the local `README.md` file inside that folder for instructions.
• Open the *src* folder and run the code!
